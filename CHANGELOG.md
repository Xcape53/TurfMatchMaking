# Turf Matchmaking 1.7.3

Added the Halloween event.

## What's new

- **Halloween event:** the **Trick or Treat** mode and the **Candy Heist** map are in the filters, so you can search for event lobbies only. **Zombies** is also selectable.
- **New maps:** Barnyard, Arena, Stockade, Frontier and Piazza are in the map filter.
- **Fix:** after a rejected lobby, Turf could leave you on a map you did not select. It now always continues the search with your filters.
- Newer modes Turf does not know yet show as "Mode #N" in the lobby list instead of being hidden.

## Updating

- **Kute:** updates automatically. The new version starts on your next reload. If you turned Automatic Updates off, use **M > Settings > Script Updates > Install Update**.
- **Other clients (Crankshaft, Glorp, KCC) and userscript managers:** download `TurfMatchMaking1.7.3.js`, install it and disable or remove the old version, then reload.

Settings, presets and player lists are kept.
